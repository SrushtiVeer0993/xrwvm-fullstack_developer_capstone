# Car Dealership Portal

## Project Overview

The Car Dealership Portal is a full-stack web application developed as part of the IBM Full Stack Software Developer Capstone Project.

The application allows users to browse car dealerships, view dealer details, filter dealerships by state, register and log in, and submit and view dealership reviews.

## Technologies Used

- **Frontend:** HTML, CSS, JavaScript, React
- **Backend:** Python, Django, Node.js, Express
- **Database:** MongoDB
- **API Integration:** REST APIs and cURL
- **CI/CD:** GitHub Actions
- **Version Control:** Git and GitHub

## Key Features

- User registration, login, and logout
- Dealer listings and dealership details
- Filtering dealerships by state
- Submitting and displaying dealership reviews
- Sentiment analysis of review text
- Car makes and models
- Automated workflow testing and deployment
